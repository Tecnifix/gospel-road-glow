# Gospel Road Glow

Estou criando um aplicativo para personalização de central multimídias. Quero que você crie prompts para me gerar telas de fundo personalizáveis. Telas de fundo no modelo gospel para pessoas religiosas. Imagem de Jesus Cristo, anjos, mas algo que bata com a sincronização da central multimídia, que tem a parte do velocímetro, do motor, do óleo. Quero que apareça diversas informações do veículo. Irei te enviar algumas fotos para você ver alguns modelos que eu já fiz, que a IA preparou para mim. Quero que você crie um prompt baseado nessas imagens para me gerar as imagens no Flow, para personalizar meus aplicativos. E, se possível, também me indique alguma IA para fazer personalização. Não, pode ser no Flow também. Pode ser no Flow. Quero fazer fundos personalizáveis que se mexam. Se possível, fazer no Flow para esse tipo de aplicativo. O que você me indica?

gere as imagens



Quero que você faça todas as funcionalidades do aplicativo funcionarem. Depois eu posso subir essa interface para o meu aplicativo no cloud e botar na estrutura do meu programa, no aplicativo, que vai ser mudar tema de multimídias. Quero que você crie vários modelos e com funções. Mais pra frente a gente escolhe botar as funções funcional ou não. Na verdade, você consegue criar aí pra mim? Deixar tudo funcional no sistema?
